Formatting Note: 

Each question can be multiple lines long, but the answer must be the very 
last line of the block. You must leave one blank line between the answer of one question 
and the start of the next to prevent the program from breaking. Example questions are
below so that you know how to format it:

What is the capital of France?
A) London
B) Paris
C) Berlin
B

Which of these are programming languages?
1. Python
2. HTML
3. Java
1 and 3
